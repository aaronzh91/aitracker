# AI Money Map (`aitracker`)

A public, weekly-updated, neutral reference for the financial structure of the AI ecosystem: the major players, how they monetize AI, and — most importantly — the money flows between them (investments, compute commitments, hardware purchases, financing structures), with two-sided accounting treatment and full source provenance on every number.

**Goal:** be the trusted source of truth for AI financials — useful to investors, operators, and regulators alike — with Wikipedia-grade auditability: every figure sourced, every estimate labeled with its method, every change versioned in git.

**Status:** Specification phase. See [`SPEC.md`](./SPEC.md) for the full product & architecture specification.

**Update rhythm:** weekly, Saturdays 8:00 pm ET, via an automated pipeline (SEC EDGAR ingest + agentic news/filings sweep) that commits data updates and a public changelog.
